"""
Explanation
This Python program solves the 0-1 Knapsack Problem using Dynamic Programming (DP). In the 0-1 Knapsack problem, each item can either be selected completely (1) or not selected (0); an item cannot be divided. The program first creates an Item structure containing the item number, value, and weight. The knapsack_dp() function creates a two-dimensional DP table where dp[i][w] represents the maximum value that can be obtained using the first i items with a maximum capacity of w. For every item and every possible capacity, the algorithm considers two choices: skip the item or take the item if its weight fits. It stores the larger of these two values in the DP table. After filling the table, dp[n][capacity] contains the maximum possible value. The selected_items() function then works backwards through the DP table to determine which items were actually selected. For the given example, the optimal solution selects Item 2 and Item 3, with a total weight of 50 and a maximum value of 220.
Time and Space Complexity
Let n be the number of items and W be the knapsack capacity.
Operation	Time Complexity	Space Complexity
Build DP table	O(nW)	O(nW)
Trace selected items	O(n)	O(n)
Overall	O(nW)	O(nW)


- Time Complexity: O(nW) — The program processes every combination of item and capacity.
- Space Complexity: O(nW) — The two-dimensional dp table contains (n+1) × (W+1) entries.
Important Functions and Concepts
1. namedtuple()
   Creates the Item structure with three fields:
   - index – item number
   - value – value of the item
   - weight – weight of the item
2. knapsack_dp(items, capacity)
   This is the main Dynamic Programming function. It builds the DP table and returns the table along with the maximum value.
3. dp = [[0] * (capacity + 1) for _ in range(len(items) + 1)]
   Creates a two-dimensional DP table. Rows represent items and columns represent different knapsack capacities.
4. enumerate(items, start=1)
   Iterates through the items while starting the item number from 1, making it convenient to match the DP table rows with items.
5. max(take, skip)
   Chooses the better option:
   - take → include the current item.
   - skip → exclude the current item.
6. selected_items(items, dp, capacity)
   Performs backtracking through the DP table to determine which items produced the maximum value.
Dynamic Programming Formula
For an item with weight weight[i] and value value[i]:

If the item fits:
dp[i][w] = max(
    dp[i-1][w], 
    value[i] + dp[i-1][w-weight[i]]
)

In simple terms:

Maximum value = maximum of (skip item, take item)

If the item does not fit:
dp[i][w] = dp[i-1][w]

because the item cannot be selected.
Example
Given:
Item	Value	Weight
1	60	10
2	100	20
3	120	30


Capacity = 50

The algorithm evaluates different combinations:
- Item 1 + Item 2 → weight = 30, value = 160
- Item 1 + Item 3 → weight = 40, value = 180
- Item 2 + Item 3 → weight = 50, value = 220
- Item 1 + Item 2 + Item 3 → weight = 60, which exceeds the capacity
Therefore:

Maximum value = 220

Selected items = Item 2 and Item 3
Conclusion
The 0-1 Knapsack problem is efficiently solved using Dynamic Programming by breaking the problem into smaller subproblems based on the number of items and available capacity. Unlike Fractional Knapsack, items cannot be divided. The algorithm considers both taking and skipping each item and stores the best result in the DP table. The final cell gives the optimal value, while backtracking identifies the selected items. Its time complexity is O(nW) and its space complexity is O(nW).

"""


# %% Step 1: Imports
from collections import namedtuple

# %% Step 2: Input items and capacity
# Each item is (index, value, weight). Change the list or the capacity and
# re-run this cell plus the steps below it.
Item = namedtuple("Item", ["index", "value", "weight"])

items = [
    Item(1, 60, 10),
    Item(2, 100, 20),
    Item(3, 120, 30),
]
capacity = 50

for item in items:
    print(f"Item {item.index}: value={item.value}, weight={item.weight}")
print("Capacity:", capacity)

# %% Step 3: Build the DP table
def knapsack_dp(items, capacity):
    """Fill the DP table; return (dp table, maximum value)."""
    dp = [[0] * (capacity + 1) for _ in range(len(items) + 1)]

    for i, item in enumerate(items, start=1):
        for w in range(capacity + 1):
            if item.weight <= w:
                take = item.value + dp[i - 1][w - item.weight]
                skip = dp[i - 1][w]
                dp[i][w] = max(take, skip)
            else:
                dp[i][w] = dp[i - 1][w]
    return dp, dp[len(items)][capacity]

# %% Step 4: Trace back the chosen items
def selected_items(items, dp, capacity):
    """Walk the table backwards and collect the item indices chosen."""
    chosen, w = [], capacity
    for i in range(len(items), 0, -1):
        if dp[i][w] != dp[i - 1][w]:
            chosen.append(items[i - 1])
            w -= items[i - 1].weight
    return chosen

# %% Step 5: Run and print the result
dp, best = knapsack_dp(items, capacity)

print(f"\nMaximum value = {best}")
print("Selected items:")
for item in selected_items(items, dp, capacity):
    print(f"  Item {item.index} (value={item.value}, weight={item.weight})")

# %% Step 6: Inspect the DP table
# Rows are items (row 0 = no items), columns are capacities from 0 to 50.
print("\nDP table (rows = items, columns = capacity):")
for row in dp:
    print(row)

# %% Step 7: Observation
print("\nObservation")
print("  Each cell stores the best value for that item prefix and capacity.")
print("  The final cell is the answer, and the trace-back finds the items.")
